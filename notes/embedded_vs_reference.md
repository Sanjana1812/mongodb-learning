# MongoDB vs PostgreSQL

MongoDB

* Document database
* Flexible schema
* JSON style documents
* Good for rapid development

PostgreSQL

* Relational database
* Structured schema
* Strong joins
* Good for enterprise applications

Examples:

MongoDB

* Chat
* Content apps
* User feeds

PostgreSQL

* Banking
* ERP
* HR Systems

* SQL + PostgreSQL
